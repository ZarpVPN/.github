# Zarp

**One-click Cloudflare WARP access for restricted networks.**

Zarp is an open-source application for Windows, macOS and Android. It automatically discovers working DPI bypass strategies using zapret2 to help connect through networks that block Cloudflare WARP.

## ✨ Features

**One-click connection** - Automatically find and save a working strategy.

**DPI bypass** - Discover strategies suitable for restricted networks.

**Multiple platforms** - Available for Windows, macOS and Android.

**Automatic recovery** - Retry verified strategies when a connection stops working.

**Advanced networking** - The Windows version supports custom VLESS, Trojan and Hysteria2 servers with routing controls.

**Open source** - Transparent development and publicly available source code.
